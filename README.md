# How it works
<img width="1335" height="729" alt="image" src="https://github.com/user-attachments/assets/00f0084d-ece7-4c5b-9c90-0990b848a7af" />

1. Paste the **PID** of the target `RobloxApp` process.
2. The program finds the target Menu ID that opens the script execution window.
3. Choose your script, then press **OK**.
4. The script is executed! It is that simple!

# Building

You need **Visual Studio 2026** with **.NET 10.0** installed to build this project.
First download the latest release in the Releases.

1. Open `SuperSimpleOldRobloxExecuteFrameOpener.slnx` in Visual Studio.
2. Wait until the solution loads completely.
3. Press `CTRL` + `SHIFT` + `B` to build the project.
4. Navigate to `SuperSimpleOldRobloxExecuteFrameOpener/bin/Debug/net10.0` (or `SuperSimpleOldRobloxExecuteFrameOpener/bin/Release/net10.0`) to find your executable file!

# Supported Versions

Currently, SSOREFO supports only legacy Roblox versions from **0.3.xxx.0** to **0.66.xxx.0** (`RobloxApp` from the 2006-2012 era).
